# @invoria/inventory — AI Agent Rules

## Module Purpose
Inventory batch management for products.

## Allowed Dependencies
- `@invoria/core`, `@invoria/utils`, `@invoria/ui`, `@invoria/event-bus`
- `@angular/core`, `@angular/common`, `@angular/forms`, `@angular/router`
- `rxjs`, `primeng/*`, `lucide-angular`

## Strict Restrictions
- Do not import catalog components directly.
- The product batches panel is embedded in the product details page via `@invoria/inventory`.
